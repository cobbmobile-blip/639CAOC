# SPECIAL INSTRUCTIONS (SPINS)
**639th Combined Air Operations Center — Dagger's Edge**

Standing for the campaign; published once (see Combined Campaign Intent, Campaign Mechanics). Covers every cycle unless superseded.

## 1. General
- **1.1** Theater: Combined Theater Bible, posted to #theater-map. All names notional.
- **1.2** Chain of command: CFC → CFACC → Combat Plans / Combat Ops / ISR / Logistics & Resources / C4-IM.
- **1.3** Classification / handling: none — training exercise, all participants briefed.

## 2. Timing
- **2.1** All times published in Zulu and game time together. Game-time offset: see #cfacc-guidance pinned post.
- **2.2** Freeze line: T-72h. Buy/Pass window closes at Confirmed status (T-72h + 15 min from first Buy).

## 3. Mission Planning
- **3.1.1** File a flight plan before every mission: departure, route, arrival, tasking. Lets AWACS and ATC deconflict.
- **3.2** Standard Conventional Load (SCL) codes apply — see TTP 1-1 §9. If no code exists for a desired loadout, flag it to your airframe lead before planning starts.
- **3.3** Killboxes and ROZs are assigned in the ATO. No engagement without terminal attack control outside an active, owned killbox.

## 4. Command and Control
- **4.1** AWACS callsign and primary/secondary frequencies: set per cycle in the Comm Plan.
- **4.2** Joint Tactical Air Support Request (JTAS) format: see your group's own C2 TTP.
- **4.3** Time-sensitive targets (TST) take precedence over briefed tasking. TST matrix published with each Combined AOD Part 2.

## 5. Reporting
- **5.1** In-flight and after-action reports use: callsign, mission number, target location, time on target, results, remarks.
- **5.2** Post BDA to #combined-aar-bda. Use SPINS-format positions so ISR can paste them directly into planning tools.
- **5.3** BDA wording: **Confirmed** (sensor/video/Tacview evidence), **Probable** (strong indicators, unverified), **Unconfirmed** (suspected, no evidence).

## 6. Emergency Procedures
- **6.1** Divert fields: see ACO.
- **6.2** Lost comms: proceed per briefed contingency, squawk 7600, continue mission profile unless safety dictates RTB.
